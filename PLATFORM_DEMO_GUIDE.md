**How to Test**:
1. Type or speak a legal question
2. Wait for response (~1 second)
3. Check the citations and references

**What's Happening Behind the Scenes**:
- Query → OpenAI embedding (text-embedding-3-large)
- Vector search in Supabase (4,225 legal chunks)
- Similarity threshold: 0.30 (6x stricter than before)
- Top 10 relevant chunks retrieved
- GPT-4o-mini generates answer with citations
- document_id tracking for verification

    "language": "ar"

**Expected Response**:
- Legal answer in Arabic

- document_id for traceability

- No hallucinated information

## 🧪 API ENDPOINTS TO TEST

### 1. **Health Check**
```bash
curl http://localhost:4001/

# Response:
{
  "message": "Mo7ami Backend with OpenAI",
  "version": "0.1.0",
  "status": "running",
  "ai_enabled": true
}
```

### 2. **Chat API** (Main Endpoint)
```bash
curl -X POST http://localhost:4001/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "كيفاش نسجل شركة؟",
    "language": "ar"
  }' | jq '.'
```

**Response Fields**:
- `answer` - Legal answer in Arabic/French
- `language` - Detected language
- `citations` - Array of legal sources
- `processing_time` - Response time in seconds
- `retrieved_chunks` - Number of documents retrieved
- `domain` - Detected legal domain

### 3. **Voice Transcription** (Whisper-1)
```bash
# Record audio first
ffmpeg -f avfoundation -i ":0" -t 3 test_audio.wav

# Transcribe
curl -X POST http://localhost:4001/api/v1/voice/transcribe \
  -F "file=@test_audio.wav" \
  -F "language=ar"
```

**Response**:
```json
{
  "text": "شنو كايقول القانون على السرقة؟",
  "confidence": 0.94,
  "language": "ar"
}
```

### 4. **Voice Synthesis** (TTS-1-HD)
```bash
curl -X POST http://localhost:4001/api/v1/voice/synthesize \
  -H "Content-Type: application/json" \
  -d '{
    "text": "مرحبا بك في محامي",
    "language": "ar",
    "voice": "female"
  }' --output welcome.mp3

# Play the audio
open welcome.mp3
```
